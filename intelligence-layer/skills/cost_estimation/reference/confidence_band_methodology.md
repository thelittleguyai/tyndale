# Confidence-band methodology

**Purpose.** Construct the ± range around the point estimate. **Tyndale never gives a bare
point estimate** — always a band with reasoning.

**Default band widths.**
- **Routine, well-defined procedures:** about **±20%** (e.g., a standard imaging study or
  lab panel with a tight FAIR Health distribution).
- **Complex or variable procedures:** about **±35%** (e.g., surgeries with variable
  components, anesthesia time, implants, or facility-fee variability).

**Inputs that widen the band.**
- Wide FAIR Health percentile spread for the procedure/area.
- Unknown or estimated benefit values (deductible amount-met not confirmed).
- Possible add-ons (pathology, anesthesia, facility fee) not yet known.
- Uncertain network status.

**How to present.**
- Lead with the range: "Expected range **$1,800–$2,400**."
- Then the reasoning: what drove the width, which sources were used.
- Name the assumptions explicitly (per the voice-tiering "genuine uncertainty" rule).

**Forbidden.** A single number with no band; a band with no stated basis; an implied
guarantee of the final price (Tier C — never predict outcomes).
