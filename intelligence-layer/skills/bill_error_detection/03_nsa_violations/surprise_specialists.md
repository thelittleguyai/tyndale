# Surprise specialists (out-of-network ancillary at in-network facility)

**What this is.** An out-of-network ancillary provider (anesthesiology, radiology,
pathology, assistant surgeon, etc.) at an in-network facility balance-bills the patient —
prohibited by the No Surprises Act, with no valid notice-and-consent available for these
ancillary services.

**Detection signals.**
- An in-network hospital/facility, but a separate out-of-network bill from an ancillary provider.
- Balance billing above in-network cost-sharing for that provider.

**Citation language.** Tier B: "For non-emergency services by an out-of-network provider at
an in-network facility, balance billing is prohibited; ancillary providers cannot obtain a
valid consent waiver [No Surprises Act, 42 U.S.C. §300gg-111(b), src_TBD]."

**Severity.** High.

**Common defenses.** Provider claims a signed consent. Response: consent is invalid for
ancillary services and emergency situations.

**Required evidence.** EOB, the facility's network status, the ancillary provider's bill,
any consent form presented.

**Recommended remediation (Tier C).** Assert NSA protection; provider/plan resolve via
open negotiation / IDR. Sequence via `negotiation_strategy`.
