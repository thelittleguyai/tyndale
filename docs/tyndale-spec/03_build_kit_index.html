Tyndale · Claude Code & Cowork Build Kit

Build it yourself, then hand it off.

A sequenced set of tasks you can hand to Claude Code and Cowork to build the parts of Tyndale's intelligence layer that don't require deep engineering judgment. Each task has a paste-ready prompt and a "done when" verification step. The phases that require Phil, Jonas, or Josh are flagged clearly at the end.

How to use this kit

Each task is a self-contained Markdown file in tasks/. Open the file, copy the entire contents, and paste it into a Claude Code session. Claude Code will execute the task. When it finishes, run the "done when" verification at the bottom of the task file to confirm the work succeeded.

Tasks are sequenced. Do them in order. Task 06 references files produced by Tasks 01–05; if you skip ahead, Claude Code won't have what it needs.

Work in your own git repo. Before starting, set up a new git repository for Tyndale's intelligence layer (e.g., tyndale-intelligence-layer). Each task commits its output. By the end of Phase 7, you'll have a complete repository ready to hand to Phil, Jonas, and Josh.

If something feels wrong, stop and ask. Claude Code is powerful but not infallible. If a task's output looks wrong to you — content, structure, anything — pause and ask Claude in the conversation thread you're using to plan this. Don't blindly proceed.

Phase 8 · Hand off to developers

What Phil, Jonas, and Josh actually build

Phase 1–7 produced the scaffolding, the content, the documentation, and the test data. Phase 8 is the engineering work that turns it into a running system. This phase is not in this build kit — it's the developer build spec (Document 2 in the deliverables set).

The engineering work that requires Phil, Jonas, Josh

  • FastAPI application architecture. The Python monolith hosting Lead Planner, subagents, hooks, and the tool layer. Production-grade error handling, request lifecycle, dependency injection.
  • Claude Agent SDK integration. Wiring the subagents, hooks (UserPromptSubmit, PreToolUse, PostToolUse, Stop), and effort-scaling logic.
  • LiteLLM proxy deployment and hardening. Self-hosted inside Azure VPC. Short-lived keys, rotated weekly. Per-route allow-lists. Audit-log integration. Fail-closed on misconfig.
  • HIPAA-compliant audit log. Postgres schema with AES-GCM field-level encryption. Azure Key Vault integration. 90-day rotation. Gated access workflow.
  • Qdrant deployment on Azure Container Apps. Self-hosted inside VPC. Daily snapshots. Performance targets enforced.
  • FHIR OAuth (SMART on FHIR + 1upHealth). Token management, refresh flow, FHIR resource parsing for Coverage, EOB, Claim.
  • Hook implementations. Presidio scrubbing, prompt injection detection, citation Layer 2 resolution, approval-token validation.
  • Stripe integration. Subscription tiers ($11.99/$100 unlimited at V1; Family $29.99 within 90 days; Chronic Care at Stage 3).
  • Postgres schema migrations. Case files, findings, deadlines, audit log, NCCI/MUE structured tables.
  • Azure infrastructure setup. Container Apps, VPC, Key Vault, Postgres Flexible Server, Blob, Monitor.
  • BAA contract execution. Sign Anthropic, Azure, AWS, 1upHealth, Postmark, Voyage, FAIR Health, Stripe, observability vendor BAAs.
  • Pre-V1 Presidio benchmark execution. Hand-labeled 200–500 medical bills/EOBs corpus; targets per developer spec.
  • Pre-V1 embedding benchmark. voyage-context-3 vs voyage-3-large on laws_regulations; 100-query legal eval set.
  • Eval platform integration. Braintrust + Arize Phoenix wiring. Per-PR smoke evals in GitHub Actions. Nightly suite.
What this kit gives the developers
Everything except the runtime
By the time Phase 7 completes, Phil/Jonas/Josh receive: every Skill written, every subagent system prompt versioned, every tool description authored, every voice and refusal rule codified, every collection schema specified, ~400 expert-labeled golden examples plus ~2,000+ synthetic adversarial cases ready for the eval suite, the BAA tracker populated, and a complete handoff brief explaining what's built and why. Their job is to wire it into a running production system.
