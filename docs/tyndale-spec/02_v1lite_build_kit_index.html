Tyndale · V1-Lite Build Kit

Build the lean version first.

A re-sequenced task set that builds V1-Lite — document upload, 3-agent intelligence layer, no letter generation, plus a feedback loop from day one. Green tasks reuse files from the full Build Kit unchanged. Amber tasks are new to V1-Lite. Read the V1-Lite Scope & Forward-Compatibility Spec before starting.

How to use this kit

Green tasks are reused from the full Build Kit. You already have these task files (Tasks 01–08, 12–15, 17–18, 23–26, 28–29). Run them exactly as written. They're shared by both versions.

Amber tasks are new — they live in this kit's tasks/ folder with an L prefix (L01, L02...). Open each, paste into Claude Code, verify with "done when."

Same repository. V1-Lite builds in the same tyndale-intelligence-layer repo as the full version. New V1-Lite files are marked with a v1lite tag in their headers so it's clear what's lean-mode vs full. Nothing conflicts.

The order matters. Foundations first (reused), then the upload path, then the collapsed agents, then the feedback loop, then the web shell. Dependencies are noted in each task.

The shape of the work
V1-Lite is roughly half the build kit, reusing the other half
You reuse ~18 of the original 32 task files unchanged, add 8 V1-Lite-specific ones, and defer ~9 (letter generation Skills, the Strategist/Legal Researcher/Code Validator standalone subagents, full eval volume) until the upgrade. The deferred tasks aren't discarded — they're your full-Tyndale backlog, ready when V1-Lite is live and generating data.
Engineering · What the team builds for V1-Lite

The runtime work for V1-Lite

Same as the full version's engineering work, minus the deferred pieces, plus the upload path and feedback loop.

V1-Lite engineering scope (Phil, Jonas, Josh)

  • Web app (Phil): mobile-friendly, upload-centric. The L07 scaffold gets production-hardened — auth, file handling, responsive polish, accessibility.
  • FastAPI monolith (Jonas): hosts the 3-agent layer, hooks, tool layer. Same as full minus the 3 deferred subagents.
  • Upload + OCR pipeline (Jonas): Azure Document Intelligence for extraction, confidence scoring, the upload_extract_* tools.
  • Qdrant + 4 collections (Josh): identical to full. Run ingestion.
  • PHI spine (Jonas + Josh): dual-stream logging, Presidio scrubbing, encrypted audit log, citation Layer 2 — all required day one.
  • Feedback loop (Jonas): capture schema, consent flow, de-identification pipeline, triage queue, golden-example promotion. Forward-compatible with full.
  • LiteLLM Claude-only routing (Jonas): identical to full.
  • Stripe (Jonas): $11.99/mo & $100/yr unlimited — same as full V1.
  • NOT in V1-Lite: FHIR OAuth, Legal Researcher / Strategist / Code Validator subagents, Document Generation / Negotiation / Charity Care Skills, the gated send-email path. All deferred to the full upgrade.
